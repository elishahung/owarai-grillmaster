# 影片標題建議產生規範

依據附在本提示末端的 `pre_pass.json`（全片摘要、人物、專有名詞、逐段摘要），為這支綜藝影片產生 3 個候選標題。

## 命名規則

1. 標題 2-8 個字，**以 2-6 字為主**。
2. **不得**出現節目名稱（中文或日文）。
3. **不得**出現任何藝人／人物名稱（見 `characters`，含本名、藝名、團名、綽號）。
4. **不得**暴雷結果（誰贏、誰輸、誰被淘汰、誰落單、誰受罰）。
5. 可以幽默影射內容，語氣貼近綜藝的吐槽感。
6. 可以直接使用該集的節目企劃名稱（`proper_nouns` 裡常有官方譯法）。
7. 標題本身不要帶日期、不要自己加 `(上)(下)`，也不要用引號或標點包裝。
8. 一律使用繁體中文；只有企劃名本身的官方英數字寫法可以保留。
9. 三個標題的取角必須不同（例如：企劃名直用／機制影射／現場張力），不要是同一個詞的變體。

## 輸出

每個標題附一句 `reason`（繁體中文，一句話）說明取這個名字的理由。輸出形狀：

```json
{
  "titles": [
    { "title": "搭檔末日", "reason": "直接沿用節目企劃名，四字有末日感，不暴雷誰落單" },
    { "title": "控比配對", "reason": "影射互相指名的配對機制，帶戲謔感" },
    { "title": "職業修羅場", "reason": "點出告白與拒絕的現場張力，不提任何藝人名" }
  ]
}
```

不要建立或修改任何檔案。你的完整輸出就是最後一則訊息：一個符合下方 schema 的 JSON 物件，前後不要有任何說明文字。
