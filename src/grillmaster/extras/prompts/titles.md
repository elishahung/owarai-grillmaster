# 影片標題建議產生規範

依據附在本提示末端的 `program.json`（來源平台上的節目系列名 `series` 與頻道 `channel`，可能為 `null`）與 `pre_pass.json`（全片摘要、人物、專有名詞、逐段摘要），為這支綜藝影片產生節目中文名與 3 個候選標題內容。

最終標題由程式組成 `節目名:標題內容 播出日期`，節目名與日期都由程式加上，你只負責 `program` 與每個 `title` 的內容部分。

## 節目名（`program`）

1. 節目在台灣通行的繁體中文全名；沒有通行譯名時，依原名意譯成繁體中文全名。可以上網查證。
2. 只寫名稱本身，不加書名號、引號、播出日期或集數。

## 標題內容（`title`）

1. 2-8 個字，**以 2-6 字為主**。
2. **不得**出現節目名稱（中文或日文），程式會加在前面。
3. 本集看點是某位來賓時，可以直接用來賓名（藝名或團名，用 `characters` 的譯法）；節目固定主持人／班底的名字不要放。
4. **不得**暴雷結果（誰贏、誰輸、誰被淘汰、誰落單、誰受罰）。
5. 可以幽默影射內容，語氣貼近綜藝的吐槽感。
6. 可以直接使用該集的節目企劃名稱（`proper_nouns` 裡常有官方譯法）。
7. 不要帶日期、不要自己加 `(上)(下)`，也不要用引號或標點包裝。
8. 一律使用繁體中文；只有企劃名、來賓名本身的官方英數字寫法可以保留。
9. 三個標題的取角必須不同（例如：企劃名直用／來賓／內容影射），不要是同一個詞的變體。

## 輸出

每個標題附一句 `reason`（繁體中文，一句話）說明取這個名字的理由。輸出形狀：

```json
{
  "program": "（節目的繁體中文全名）",
  "titles": [
    { "title": "搭檔末日", "reason": "直接沿用節目企劃名，四字有末日感，不暴雷誰落單" },
    { "title": "控比配對", "reason": "影射互相指名的配對機制，帶戲謔感" },
    { "title": "職業修羅場", "reason": "點出告白與拒絕的現場張力，不提任何藝人名" }
  ]
}
```

不要建立或修改任何檔案。你的結果是一個符合下方 schema 的 JSON 物件，前後不要有任何說明文字。
