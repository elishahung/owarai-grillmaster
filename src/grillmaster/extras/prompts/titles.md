# 影片標題建議產生規範

依據附在本提示末端的 `source.json` 與 `pre_pass.json`，為這支綜藝影片產生節目中文名，並從五個角度各取一個標題內容。

最終標題由程式組成 `節目名:標題內容 播出日期`，節目名與日期都由程式加上，你只負責 `program` 與各角度的 `title`。

## 輸入

- `source.json`：來源平台公開的資訊。`series` 節目系列名、`channel` 頻道、`title` 官方集名、`description` 官方介紹、`talents` 官方出演者；任何一項都可能是 `null` 或空的。官方集名與介紹通常寫著企劃名與來賓，是主要依據。
- `pre_pass.json`：全片摘要、人物、專有名詞、逐段摘要，**包含後段的發展與結果**，只用來理解這集在做什麼、確認譯名。

## 不劇透（`title` 與 `basis` 都適用）

挑標題的人和看標題的觀眾都還沒看過這集。`title` 與 `basis` 只能寫出開播前就知道的事：

- 官方集名、介紹、出演者寫明的企劃名、來賓與設定；
- 這集一開始就交代的規則與設定。

不得寫出：誰贏誰輸、誰被淘汰／受罰／落單、挑戰或比賽的成敗、中途的轉折或意外、出演者的反應（哭、怒、崩潰、被吐槽）、哪段最好笑。也不要寫「不透露結果」「不暴雷」之類的說明：說有結果可藏，本身就是暗示。

官方集名與介紹也可能預告發展（某人發怒、某事失敗、結局如何）。只交代來賓、企劃、設定的部分可以用；講到結果或會影響期待的部分，照上面的標準刪掉。

## 節目名（`program`）

1. 節目在台灣通行的繁體中文全名；沒有通行譯名時，依原名意譯成繁體中文全名。可以上網查證。
2. 只寫名稱本身，不加書名號、引號、播出日期或集數。

## 五個角度

| 欄位 | 角度 | 寫法 | 字數 |
|---|---|---|---|
| `translation` | 翻譯 | 官方集名的中文版：去掉節目名，譯成繁體中文再剪短，留下企劃名、來賓與設定，刪掉預告發展的部分 | 2–14 |
| `project` | 企劃 | 本集的企劃／單元名稱：優先用 `proper_nouns` 的譯法，或上網查節目官方的企劃名。取大家會叫的短名，去掉「決定戰」「大會」「SP」之類的修飾 | 2–10 |
| `summary` | 概述 | 一句話說這集在做什麼，只講設定 | 2–12 |
| `talent` | 藝人 | 本集主要來賓，最多兩組，以「、」分隔；組合寫團名；固定主持人與班底不寫 | 2–24 |
| `creative` | 創意 | 有梗、吸睛但不誤導的說法，語氣貼近綜藝的吐槽感 | 2–10 |

這集沒有具名企劃（專訪、自由談話等）時，`project` 填 `null`，不要自己造一個企劃名。其他四個角度一律要給。

共同規則：

1. **不得**出現節目名稱（中文或日文），程式會加在前面。
2. 不帶日期、集數、`(上)(下)`、`Part`，也不要用引號或書名號包裝。
3. 一律使用繁體中文；只有企劃名、來賓名本身的官方英數字寫法可以保留。
4. 人名用 `characters` 的譯法。
5. 各角度的內容盡量不同；兩個角度寫出來一樣時，換一個說法。

## 依據（`basis`）

每個標題附一句 `basis`（繁體中文，一句話），只說這個標題取自哪裡、怎麼取捨，例如「官方集名去掉節目名後的精簡譯法」「`proper_nouns` 裡企劃名的官方譯法」「官方出演者中的兩組來賓」。不要描述節目裡發生了什麼。

## 輸出

```json
{
  "program": "（節目的繁體中文全名）",
  "translation": { "title": "新人組合初登場挑戰", "basis": "官方集名去掉節目名，刪掉預告結局的後半句" },
  "project": { "title": "猜拳王", "basis": "官方企劃名「〇〇じゃんけん王決定戦」的短稱" },
  "summary": { "title": "全員猜拳爭獎金", "basis": "官方介紹交代的遊戲設定" },
  "talent": { "title": "甲組合、乙先生", "basis": "官方出演者中的兩組來賓" },
  "creative": { "title": "出拳前先心理戰", "basis": "從開場說明的規則延伸" }
}
```

不要建立或修改任何檔案。你的結果是一個符合下方 schema 的 JSON 物件，前後不要有任何說明文字。
