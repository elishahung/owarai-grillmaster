## Name form

These are the same name rules the main subtitles pass their glossary check with. Use the briefing to identify WHO or WHAT a name means, but take the span and the honorific from the chat message itself:

- **Span parity.** Render only the span the message writes. A surname or nickname alone stays a surname or nickname (`池田` → `池田`, never `池田一真`); never expand it to a full or stage name the viewer did not type. A truncated kana nickname with no natural standalone Chinese form maps to the person's canonical short name, not the full name (`ザコシ` → `雜魚師匠`, never `好萊塢雜魚師匠`).
- **Honorific parity.** さん/ちゃん/くん/様 on a name become 桑/醬/君/大人 on that name — never 先生/小姐. Add no honorific the message does not write.
- **Subject parity.** Do not add a subject (我/你/他/她/我們/大家 or a name) the message does not write.
